HNC Career Path Predictor – Bonus Project

Technologies: C#, WPF, Visual Studio
Project Type: HNC Bonus Project
Grade: A

This project was a bonus assignment from our lecturer, designed as an “easter egg” to demonstrate the career opportunities available after completing the HNC.

Project Overview

We developed a C# WPF application that allowed users to:

Input their grades for all modules, one by one

Automatically calculate and display the final grade

Provide guidance on the next steps in their academic or career path

Redirect users to a UCAS “How to Apply” page for further action

Technical Details

Data Management: Utilized arrays and lists to store user input and calculate results dynamically

Development Practices:

Comprehensive documentation covering project workflow

Testing strategies to ensure accurate grade calculation

Debugging and iterative improvement to handle complex input scenarios

Outcome

Although the project was challenging at the time—requiring careful handling of arrays, lists, and dynamic data—it was a valuable learning experience. I successfully completed the project with a top grade (A), and it reinforced my skills in C#, WPF, data management, and application logic.

Looking back, projects like this made college a highly enjoyable and formative experience, laying a strong foundation for future software engineering studies.
